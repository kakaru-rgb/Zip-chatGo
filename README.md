# 1. 집찾GO: AI 기반 맞춤형 부동산 탐색 플랫폼

## 2. 데모 페이지

https://kakaru-rgb.github.io/Zip-chatGo/

## 3. 프로젝트 개요

**집찾GO(Zip-chatGo)**는 직방·다방과 같은 부동산 플랫폼을 참고하여 제작한 팀 프로젝트입니다. 사용자가 원하는 주거 조건을 AI 대화 형식으로 정리하고, 지도 기반 매물 정보와 지역별 부동산 시장 데이터를 함께 비교할 수 있도록 구성했습니다.

현재 프로젝트는 HTML, CSS, JavaScript 중심의 프론트엔드 프로토타입과 국토교통부 실거래가 OpenAPI를 중계하는 Node.js 서버로 이루어져 있습니다. 지도 탐색, 시장동향 분석, 회원가입·로그인, 매물 등록, 이용가이드, 고객센터, 서비스 소개 등 부동산 플랫폼의 주요 사용자 흐름을 화면으로 구현했습니다.

일부 기능은 실제 외부 API 또는 로컬 JSON 데이터와 연결되어 있으며, AI 추천·회원 인증·문의 등록 등은 서비스 흐름을 보여주기 위한 시연용 기능으로 구현되어 있습니다.

## 4. 프로젝트 목표

- 대화형 인터페이스를 활용한 사용자 맞춤 주거 조건 수집
- 지도와 매물 데이터를 결합한 직관적인 부동산 탐색 경험 제공
- 매매·전세·거래량 등 시장 데이터를 활용한 의사결정 지원
- 부동산 플랫폼의 주요 기능을 하나의 일관된 사용자 흐름으로 연결
- PC, 태블릿, 모바일 환경을 고려한 반응형 UI 구현
- 실제 API와 데이터베이스를 연결할 수 있는 확장 가능한 서비스 구조 마련

## 5. 기획 의도

기존 부동산 플랫폼은 많은 매물과 시장 정보를 제공하지만, 사용자가 자신의 조건에 맞는 정보를 직접 선별해야 한다는 어려움이 있습니다. 집찾GO는 사용자가 알고 있는 조건부터 자연스럽게 입력하면 필요한 기준을 단계적으로 정리하고, 추천 지역·지도 매물·시장 분석 자료로 연결하는 서비스를 목표로 기획했습니다.

사용자는 메인 페이지에서 AI와 대화를 시작하고, 지도에서 지역과 매물을 탐색한 뒤, 시장동향 페이지에서 가격과 거래 흐름을 비교할 수 있습니다. 매물을 등록하려는 사용자를 위한 단계형 등록 화면과 서비스 이용을 돕는 안내·고객지원 화면도 함께 구성하여 부동산 플랫폼의 전체적인 이용 흐름을 구현하고자 했습니다.

## 7. 주요 구현 기능

### 7.1 메인 페이지

- 집찾GO 브랜드와 AI 기반 집 찾기 콘셉트 소개
- AI에게 보낼 첫 메시지 입력 및 추천 질문 태그 제공
- 입력한 메시지를 AI 대화 페이지로 전달
- 서비스 소개, 지도 탐색, 시장동향, 매물 등록 바로가기
- 로그인 상태에 따른 헤더 메뉴 변경
- 모바일 메뉴와 반응형 레이아웃

### 7.2 AI 대화형 집 찾기

- 지역, 예산, 주거 형태, 중요 조건을 단계적으로 질문
- 빠른 답변 버튼과 직접 입력 기능
- 현재까지 입력한 조건과 진행률 표시
- 조건을 바탕으로 추천 지역 카드 제공
- 지역 시장 데이터 페이지로 이동
- 대화 초기화 및 추가 조건 입력

현재 AI 대화는 생성형 AI API가 아닌 미리 정의된 질문 흐름과 추천 규칙으로 동작하는 시연용 기능입니다.

### 7.3 지도 기반 매물 탐색

- Naver Maps JavaScript API를 활용한 지도 표시
- 조사한 지역·매물 정보를 `properties.json`에서 불러와 시각화
- 지역, 단지명, 주소 키워드 검색
- 아파트, 오피스텔, 빌라 유형 필터
- 가격 범위 필터
- Supercluster를 활용한 대량 매물 마커 클러스터링
- 확대 단계에 따른 지역 및 개별 매물 정보 전환
- 마커 선택 시 매물 카드와 상세 정보창 표시

### 7.4 시장동향 분석

- 부동산 시장동향 종합 화면
- 매매가격 및 전세가격 변화 분석
- 거래량과 지역별 거래 흐름 분석
- 기준 지역과 비교 지역 선택
- 금리, 학군, 교통 관련 지표 제공
- SVG 기반 차트와 데이터 표 구성
- 시장 상황을 요약하는 AI 리포트 형식의 화면
- 국토교통부 아파트 매매·전월세 실거래가 OpenAPI 연동 구조
- API 키가 없을 때 시연용 데이터로 동작하는 폴백 처리

### 7.5 로그인 및 회원가입

- 로그인·회원가입 탭 전환
- 일반 회원과 공인중개사 유형 선택
- 이메일과 비밀번호 입력 검증
- 비밀번호 표시 및 숨김
- 약관 전체 동의 기능
- 게스트 체험 로그인
- 로그인 상태에 따른 메뉴 변경 및 로그아웃

현재 회원 정보와 로그인 상태는 `localStorage`에 저장되는 프론트엔드 데모 방식이며, 실제 인증 서버와 회원 데이터베이스는 연결되어 있지 않습니다.

### 7.6 매물 등록

- 기본정보 → 상세정보 → 사진 → 확인·등록의 4단계 등록 과정
- 주택 및 거래 유형 선택
- 주소, 면적, 층수, 방·욕실 수 입력
- 주차, 엘리베이터, 반려동물 등 편의 조건 선택
- 사용자 정의 특징 태그 추가
- 여러 장의 이미지 선택 및 미리보기
- 가격과 연락처 입력
- 입력 내용이 반영되는 실시간 매물 미리보기

현재 등록 완료 후 서버 또는 데이터베이스에 매물을 영구 저장하는 기능은 연결되어 있지 않습니다.

### 7.7 이용가이드 및 고객센터

- 회원가입, AI 집 찾기, 지도 비교, 시장동향, 관심매물, 매물 등록 이용 절차 안내
- 카테고리별 가이드와 FAQ 제공
- 고객센터 질문 검색과 FAQ 분류
- 1:1 문의 입력 및 유효성 검사
- 문의 내용을 `localStorage`에 임시 저장

### 7.8 서비스 소개

- 집찾GO의 서비스 목적과 핵심 기능 소개
- AI 추천, 지도 탐색, 시장 데이터 활용 과정 설명
- 사용자가 서비스의 전체 이용 흐름을 이해할 수 있는 안내 콘텐츠 제공
- 브랜드 이미지와 서비스 특징을 보여주는 반응형 화면 구성

## 9. 기술 스택

### Frontend

- **HTML5**: 시맨틱 마크업과 페이지 구조
- **CSS3**: Flexbox, Grid, 반응형 레이아웃, 전환 효과
- **JavaScript (ES6+)**: DOM 조작, 이벤트 처리, 비동기 데이터 요청
- **Naver Maps JavaScript API**: 지도와 매물 마커 표시
- **Supercluster**: 지도 마커 클러스터링
- **Tabler Icons / Font Awesome**: UI 아이콘
- **Web Storage API**: 로그인, 문의, AI 첫 메시지 임시 저장

### Backend / Data

- **Node.js / Express**: 정적 파일 제공 및 시장동향 API 서버
- **fast-xml-parser**: 공공데이터 XML 응답 변환
- **dotenv**: API 키와 서버 환경 변수 관리
- **국토교통부 실거래가 OpenAPI**: 아파트 매매·전월세 데이터
- **JSON**: 조사한 지역 및 샘플 매물 데이터 관리

### Collaboration / Deployment

- **Git / GitHub**: 버전 관리와 팀 협업
- **GitHub Pages**: 프론트엔드 데모 배포

## 11. 실행 방법

### 11.1 저장소 내려받기

```bash
git clone https://github.com/kakaru-rgb/Zip-chatGo.git
cd Zip-chatGo/server
```

### 11.2 의존성 설치

```bash
npm install
```

### 11.3 환경 변수 설정

실제 국토교통부 실거래 데이터를 사용하려면 `server/.env` 파일을 생성합니다. 서비스 키가 없으면 시장동향 API는 데모 데이터를 반환합니다.

```env
PORT=3000
MOLIT_SERVICE_KEY=발급받은_서비스키
DEFAULT_LAWD_CD=41117
DEFAULT_DEAL_YMD=202606
```

### 11.4 서버 실행

```bash
npm start
```

브라우저에서 `http://localhost:3000`에 접속합니다.

## 13. 추가 구현이 필요한 기능

- **매물 검색 페이지**: 지역, 가격, 면적, 거래 유형, 주택 유형을 조합하는 상세 검색과 결과 정렬 기능
- **마이페이지**: 회원 정보 수정, 등록 매물 관리, 문의 내역, 최근 본 매물 제공
- **관심매물 기능**: 관심매물 저장·삭제, 목록 조회, 로그인 사용자별 데이터 관리
- **매물 상세 페이지**: 이미지 갤러리, 상세 조건, 중개사 정보, 위치 및 주변 시설 제공
- **실제 회원 인증**: 비밀번호 암호화, 세션 또는 토큰 인증, 소셜 로그인 연동
- **데이터베이스 연결**: 회원, 매물, 관심매물, 문의, 조회 기록을 서버에 영구 저장
- **실제 AI 추천 연동**: 사용자의 자연어 조건을 구조화하고 실제 매물 데이터에서 추천 결과 생성
- **매물 등록 관리**: 등록·수정·삭제, 이미지 업로드, 관리자 또는 중개사 검수 과정
- **지도 검색 고도화**: 현재 지도 영역 재검색, 교통·학교·편의시설 레이어, 사용자 현재 위치 검색
- **시장 데이터 확대**: 더 많은 지역과 기간 지원, 실거래 상세 조회, 그래프 데이터 다운로드
- **알림 기능**: 관심 지역의 신규 매물과 가격 변동 알림
- **관리자 페이지**: 회원, 매물, 문의 및 신고 콘텐츠 관리

## 14. 개선 및 보완 사항

### 14.1 CSS 구조 수정 및 디자인 통일

- 페이지별로 중복된 헤더, 푸터, 버튼, 폼 스타일을 공통 CSS로 통합
- 색상, 글꼴, 여백, 버튼 크기, 카드 모양을 디자인 토큰으로 관리
- 서로 다른 페이지에서 사용된 클래스 이름과 반응형 기준 통일
- 모바일, 태블릿, 데스크톱 화면별 깨짐 현상 수정
- 사용하지 않는 스타일 제거 및 CSS 파일 역할 재정리
- 포커스 표시, 색상 대비, 키보드 조작 등 웹 접근성 개선

### 14.2 서비스 안내 페이지 완성

- 현재 기본 구현된 서비스 소개 화면의 콘텐츠와 시각 요소 보강
- 집찾GO의 핵심 기능, 이용 대상, 이용 순서를 명확하게 설명
- AI 추천 → 지도 탐색 → 시장 분석 → 매물 문의로 이어지는 사용자 흐름 시각화
- 이용가이드 및 고객센터와 중복되는 내용을 정리하고 각 페이지의 역할 구분
- 실제 서비스 화면 캡처 또는 기능 미리보기 카드 추가
- 파일명 `Servise.html`을 의미에 맞는 `service.html`로 정리하고 연결 경로 수정

### 14.3 페이지 연결 구조 효율화

- 루트 절대경로와 상대경로가 혼재된 링크를 하나의 규칙으로 통일
- 모든 페이지에서 공통으로 사용할 헤더·푸터 내비게이션 구조 정리
- 존재하지 않는 관심매물 페이지와 비어 있는 페이지로 향하는 링크 수정
- 로그인 필요 기능에 공통 접근 제어 및 로그인 후 원래 페이지 복귀 적용
- 중복된 메뉴 마크업을 공통 컴포넌트 또는 JavaScript 템플릿으로 관리
- GitHub Pages의 하위 경로와 로컬 Express 환경에서 모두 동작하도록 URL 구조 개선
- 현재 위치와 이전 페이지를 쉽게 확인할 수 있도록 활성 메뉴 및 이동 경로 표시

### 14.4 코드 및 데이터 품질 개선

- 일부 파일에 남아 있는 한글 인코딩 깨짐과 오탈자 수정
- 반복되는 JavaScript 로직을 공통 모듈로 분리
- 지도 API 클라이언트 키와 공공데이터 서비스 키를 안전한 환경 설정으로 관리
- JSON 데이터 필드명, 가격 단위, 지역 코드 형식 통일
- 폼 입력 검증과 오류 메시지 표현 방식 통일
- 주요 기능에 대한 브라우저 테스트와 예외 상황 처리 추가

## 15. 향후 발전 방향

- 실제 매물 데이터와 사용자 행동 데이터를 결합한 개인화 추천
- AI가 추천 이유와 지역별 장단점을 함께 설명하는 분석 기능
- PWA 적용을 통한 모바일 설치 및 일부 오프라인 지원
- 이미지 최적화, 지연 로딩, JavaScript 모듈화를 통한 성능 개선
- 다국어 지원과 접근성 기준 강화
- 실시간 채팅, 중개사 상담, 신규 매물 알림 기능 도입
- 테스트 자동화와 배포 파이프라인 구축

## 16. 기대 효과

- **의사결정 지원**: 매물 정보와 시장 흐름을 함께 제공하여 비교 기준 강화

- **팀 협업 경험 강화**: 페이지별 역할 분담과 Git 기반 통합 과정을 통한 협업 역량 향상
